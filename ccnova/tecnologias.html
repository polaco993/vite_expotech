Construção

HTML

Linguagem usada para criar a estrutura de páginas web. Com ele, organizamos conteúdos como títulos, parágrafos, imagens e links, formando a base de qualquer site.

CSS

Responsável pela aparência das páginas. Ele permite estilizar elementos do HTML, definindo cores, fontes, espaçamentos e layouts, deixando o site mais bonito e organizado.

JAVASCRIPT

Linguagem de programação que traz interatividade para o site. Com ele, é possível criar animações, validar formulários e responder às ações do usuário em tempo real.

VScode

Editor de código gratuito e muito popular entre desenvolvedores. Ele oferece recursos como destaque de sintaxe, sugestões automáticas, extensões e integração com várias linguagens. É uma ferramenta prática para escrever, editar e organizar códigos de forma eficiente.
